# AST、Coder 与 VM 内存现状

记录于 2026-11-26。这是内存重设计的讨论背景，不是已定方案。

当前结构分为 AST、Coder、VM 三层。Coder 生成中间代码，让主线程快速把文件内容合并到 VM；Coder 生成关系图，VM 按需求值。

主线程始终持有所有文件的关系图。全局诊断完成后，可以视为主线程也持有所有文件的求值结果。主线程通常只保留少量 AST。

主要内存开销来自 VM：关系图和求出的值同时驻留，两者都抽象为 `Node`。图中包含大量中间表示，并记录依赖关系，以便增量淘汰缓存、下次查询时重新求值。

当前 Coder 生成的是静态关系图，无法表示收窄。主线程要计算收窄，还需要控制流图；控制流图、关系图和求值结果是三类不同的数据。
